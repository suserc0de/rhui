Components, Props & Slots

Components are the primary building blocks of RHUI. They encapsulate markup, styles, and logic into self-contained, reusable custom tags.

1. Defining a Component

A component is declared inside a .rhui file using the <component name="..."> block:

templates/components/Button.rhui 
<component name="Button">
  <props>
    <prop name="variant" default="primary" />
    <prop name="href" default="" />
  </props>

  <if test="href != ''">
    <a :href="href" class="btn btn-{{ variant }}">
      <slot />
    </a>
  </if>
  <else>
    <button type="button" class="btn btn-{{ variant }}">
      <slot />
    </button>
  </else>
</component>

2. Invoking Components

Use the prefix <ui:ComponentName> to call your registered component from any page or other component:

templates/pages/index.rhui 
<!-- Literal prop and link button -->
<ui:Button variant="secondary" href="/login">
  Log In
</ui:Button>

<!-- Standard button -->
<ui:Button variant="primary">
  Save Changes
</ui:Button>

3. Fallback Content in Slots

Provide default markup inside <slot> that renders automatically if the caller does not supply content:

templates/components/Modal.rhui 
<component name="Modal">
  <div class="modal">
    <div class="modal-body">
      <slot>
        <p class="text-muted">No content provided.</p>
      </slot>
    </div>
  </div>
</component>

4. Named Slots & Conditional `has_slot`

Use named slots (<slot:name>) for complex UI compositions like cards, modals, or page headers:

templates/components/Card.rhui 
<component name="Card">
  <div class="card">
    <div class="card-body">
      <slot />
    </div>

    <!-- Only render footer wrapper if caller provided slot:footer -->
    <if test="has_slot('footer')">
      <div class="card-footer">
        <slot:footer />
      </div>
    </if>
  </div>
</component>

5. Dynamic Attribute Spreading (`:attrs`)

Forward arbitrary HTML attributes (such as hx-get, id, data-*, or aria-*) to an underlying element without listing them in <props>:

Usage 
<!-- Component Definition -->
<component name="CustomInput">
  <input class="form-control" :attrs="extra_attrs" />
</component>

<!-- Caller passes unmapped attributes automatically via extra_attrs -->
<ui:CustomInput id="user-email" type="email" placeholder="you@email.com" required="true" />
