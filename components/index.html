Components & Slots

Create declarative, encapsulated UI components with typed props, fallback slot content, multi-slot projection, and rest-attribute forwarding.

Defining Components

In RHUI, a component is an encapsulated template wrapped in a <component name="..."> root tag. Component files placed in your views directory are automatically registered.

views/components/Badge.rhui 
<component name="Badge">
  <props variant="info" />

  <span class="badge badge-{{ variant }} px-2 py-0.5 rounded text-xs">
    <slot />
  </span>
</component>

Declaring Props & Default Values

Declare acceptable parameters via <props />. Any attribute passed to <props> serves as the fallback default when omitted by the consumer.

views/components/Alert.rhui 
<component name="Alert">
  <props title="Notification" type="info" dismissible="false" />

  <div class="alert alert-{{ type }} p-4 rounded-lg">
    <strong class="font-bold">{{ title }}</strong>
    <div class="mt-1 text-sm"><slot /></div>
  </div>
</component>

Invoking Components with <ui:Name>

Invoke any registered component in templates using the <ui:ComponentName> custom tag syntax. Props can be static strings or dynamic evaluated expressions:

views/pages/home.rhui 
<!-- Static props and inner content into default slot -->
<ui:Badge variant="success">Online</ui:Badge>

<!-- Dynamic evaluated props -->
<ui:Alert title="System Warning" type="danger">
  Database latency is exceeding {{ latencyThreshold }}ms!
</ui:Alert>

Default & Fallback Slots

A <slot> tag can contain default fallback content that only renders when the caller passes no children:

views/components/Button.rhui 
<component name="Button">
  <props type="button" />

  <button type="{{ type }}" class="btn px-4 py-2 rounded bg-brand-600 text-white font-medium">
    <slot>Click Here</slot>
  </button>
</component>

Named Slots & Multi-Zone Projection

Project content into distinct named target locations inside a component with <slot:header> and <slot:footer>:

views/components/Modal.rhui 
<component name="Modal">
  <div class="modal-dialog">
    <if condition=has_slot('header')>
      <header class="modal-header"><slot:header /></header>
    </if>

    <div class="modal-body"><slot /></div>

    <if condition=has_slot('footer')>
      <footer class="modal-footer"><slot:footer /></footer>
    </if>
  </div>
</component>

Attribute Spreading with :attrs

Forward undeclared HTML attributes (e.g. hx-post, aria-*, data-*) directly into root or child tags using :attrs:

views/components/Input.rhui 
<component name="Input">
  <props label="" />

  <div class="form-group">
    <if condition=label != ''>
      <label class="block text-xs font-semibold mb-1">{{ label }}</label>
    </if>
    <input class="border rounded px-3 py-2 bg-slate-900 w-full" :attrs />
  </div>
</component>
