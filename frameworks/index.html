Multi-Framework Adapters

RHUI provides first-class renderer adapters that plug directly into existing Go web router APIs without altering your application's handler architecture.

Gin Adapter

adapter/gin

The Gin adapter implements render.HTMLRender. Assign it to router.HTMLRender and invoke c.HTML(status, templateName, data).

gin_example.go 
package main

import (
    "github.com/gin-gonic/gin"
    "github.com/suserc0de/rhui"
    "github.com/suserc0de/rhui/adapter/gin"
)

func main() {
    engine := rhui.NewEngine(rhui.EngineOptions{ViewsDir: "./views"})
    r := gin.Default()

    // Attach RHUI as Gin's HTML renderer
    r.HTMLRender = rhuigin.New(engine)

    r.GET("/", func(c *gin.Context) {
        c.HTML(200, "home.rhui", gin.H{
            "Title": "Welcome to Gin + RHUI",
        })
    })

    r.Run(":8080")
}

Echo Adapter

adapter/echo

Implements the standard echo.Renderer interface.

echo_example.go 
package main

import (
    "github.com/labstack/echo/v4"
    "github.com/suserc0de/rhui"
    "github.com/suserc0de/rhui/adapter/echo"
)

func main() {
    engine := rhui.NewEngine(rhui.EngineOptions{ViewsDir: "./views"})
    e := echo.New()

    // Attach RHUI as Echo renderer
    e.Renderer = rhuiecho.New(engine)

    e.GET("/", func(c echo.Context) error {
        return c.Render(200, "home.rhui", echo.Map{
            "Title": "Echo + RHUI",
        })
    })

    e.Start(":8080")
}

Fiber Adapter

adapter/fiber

Compatible with Fiber v2 / v3 views engine (fiber.Views).

fiber_example.go 
package main

import (
    "github.com/gofiber/fiber/v2"
    "github.com/suserc0de/rhui"
    "github.com/suserc0de/rhui/adapter/fiber"
)

func main() {
    engine := rhui.NewEngine(rhui.EngineOptions{ViewsDir: "./views"})

    app := fiber.New(fiber.Config{
        Views: rhuifiber.New(engine),
    })

    app.Get("/", func(c *fiber.Ctx) error {
        return c.Render("home.rhui", fiber.Map{
            "Title": "Fiber + RHUI Fast Performance",
        })
    })

    app.Listen(":8080")
}

Chi & Standard net/http

adapter/chi

Provides idiomatic helper functions Render(w, template, data) and RenderWithLayout(w, layout, template, data) compatible with Chi and any http.Handler.

chi_example.go 
package main

import (
    "net/http"
    "github.com/go-chi/chi/v5"
    "github.com/suserc0de/rhui"
    "github.com/suserc0de/rhui/adapter/chi"
)

func main() {
    engine := rhui.NewEngine(rhui.EngineOptions{ViewsDir: "./views"})
    adapter := rhuichi.New(engine)

    r := chi.NewRouter()

    r.Get("/", func(w http.ResponseWriter, r *http.Request) {
        adapter.Render(w, "home.rhui", map[string]any{
            "Title": "Chi + RHUI Router",
        })
    })

    http.ListenAndServe(":8080", r)
}
