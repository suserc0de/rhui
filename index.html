Familiar Component Syntax. Pure Go Power.

Write reusable UI components just like modern web frameworks, but executed purely server-side with zero build steps.

Component Definition (views/components/Card.rhui)
Card.rhui 
<component name="Card">
  <props title="Default Title" badge="" />
  
  <div class="card border rounded-xl p-4 bg-slate-800">
    <div class="flex justify-between items-center mb-2">
      <h3 class="font-bold text-white">{{ title | upper }}</h3>
      <if condition=badge != ''>
        <span class="badge bg-brand-500/20 text-brand-300">{{ badge }}</span>
      </if>
    </div>

    <div class="card-body text-slate-300">
      <slot>No description provided.</slot>
    </div>
  </div>
</component>

Modern Components

Self-contained templates with typed props, default fallback slots, named slot projections, and attribute spreading.

Contextual Security

Automated contextual escaping for HTML bodies, quoted attributes, and URLs preventing XSS injection without manual escaping flags.

Realtime SSE Streaming

Push live server-rendered component updates directly over Server-Sent Events to browser DOM elements using HTMX.

Turnkey Adapters

Ready-to-use adapter renderers for Gin, Echo, Fiber, Chi, and standard net/http in a single line of setup.

17,000+ RPS Throughput

Internal AST reuse, concurrent buffer recycling with sync.Pool, and sub-millisecond p95 latency under 10k connections.

Built-in SEO Tools

Built-in XML sitemap generation, dynamic robots.txt builder, and Schema.org JSON-LD structured data generators.
