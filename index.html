Declarative Syntax. Familiar DX.

Define custom components once, reuse them with dynamic props anywhere.

components/Card.rhui Component Definition 
<component name="Card">
  <props>
    <prop name="title" default="Default Title" />
    <prop name="variant" default="elevated" />
  </props>

  <div class="card card-{{ variant }}">
    <div class="card-header">
      <h3>{{ title }}</h3>
    </div>
    <div class="card-body">
      <!-- Default Slot -->
      <slot />
    </div>
    <div class="card-footer">
      <!-- Named Slot -->
      <slot:footer />
    </div>
  </div>
</component>
pages/users.rhui Page Usage 
<Layout title="User Dashboard">
  <ui:Card title="Members List" :disabled="false">
    <if test="len(Users) > 0">
      <each items="Users" as="u">
        <p :class="@even ? 'bg-gray' : ''">
          {{ @count }}. {{ u.Name | upper }}
        </p>
      </each>
    </if>
    <else>
      <p>No users registered yet.</p>
    </else>

    <slot:footer>
      <button class="btn">Add Member</button>
    </slot:footer>
  </ui:Card>
</Layout>

Architectural Highlights

Why Developers Love RHUI

Everything you need to build fast, secure, component-based monolithic web applications in Go.

Reusable Component Tree

Encapsulate UI into components with strict props contracts, default values, default slots, and named slots without boilerplate.

Contextual XSS Escaping

Zero-trust by default. Text, attributes, and URL schemes (javascript:) are strictly escaped and sanitized.

Live Component Streaming (SSE)

Native Server-Sent Events package (rhui/sse) to broadcast rendered UI updates in real-time to HTMX and Datastar.

Sandboxed Evaluator

Supports field traversal, logical and comparison operators, pipes, and built-ins (len, has_slot) without arbitrary Go execution.

Single Static Binary

Ship your entire web app as one binary using Go's //go:embed via rhui.WithFS(templateFS).

HTMX Fragment Rendering

Render partial nodes with engine.RenderFragment to deliver minimal HTML updates with maximum speed.

Framework Agnostic Core

Use RHUI seamlessly with your favorite Go HTTP router or standard library.

Gin

Implements native render.HTMLRender

r.HTMLRender = rhuigin.New(e)
r.GET("/", func(c *gin.Context) {
  c.HTML(200, "page", data)
})
Echo

Implements native echo.Renderer

e.Renderer = rhuiecho.New(e)
e.GET("/", func(c echo.Context) {
  return c.Render(200, "page", d)
})
Fiber

Implements native fiber.Views

app := fiber.New(fiber.Config{
  Views: rhuifiber.New(e),
})
c.Render("page", d)
Chi / net/http

Functional helpers for http.ResponseWriter

rhuichi.Render(w, 200, e,
  "pages/dashboard", data)
Real-time SSR

Stream Live Components over Server-Sent Events

Skip WebSockets. Push reactive UI components straight to the browser with broker.BroadcastComponent. Seamless integration with HTMX hx-ext="sse" or Datastar.

1. Go Backend (Event Producer)
broker.BroadcastComponent(engine, 
  "components/Notification", data, 
  sse.EventOptions{
    EventName: "NewNotification",
  })
2. HTML Client (HTMX SSE)
<div hx-ext="sse" 
     sse-connect="/events" 
     sse-swap="NewNotification" 
     hx-swap="afterbegin">
</div>

Syntax Quick Reference

Everything you need to write `.rhui` templates.

Syntax Description Example
<ui:Name> Invoking a registered component <ui:Button variant="primary">Submit</ui:Button>
:attr="expr" Dynamic expression binding <button :disabled="User.IsActive == false" />
{{ val | filter }} Piped filter formatting {{ Price | rupiah }}, {{ Name | upper }}
<slot>fallback</slot> Default slot with fallback content <slot><p>Default placeholder</p></slot>
<slot:name> Named slot container/target <slot:actions><button>Edit</button></slot:actions>
@first, @last, @index Loop context metadata variables <tr :class="@even ? 'bg-gray' : ''">
:attrs="map" Dynamic attribute spreading <input class="form" :attrs="extra_attrs" />
fragment="id" Partial fragment target for HTMX <table fragment="table-rows">...</table>
