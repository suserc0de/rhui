Why RHUI Scales Under Concurrency

Pre-Parsed Immutable AST

Templates are parsed once during initialization into an immutable tree. Concurrent render requests read from the tree without lock contention.

sync.Pool Buffer Recycling

Output buffers are obtained from Go's concurrent sync.Pool and recycled immediately upon write completion, avoiding garbage collection pauses.

Reproduce Benchmarks Locally

Clone the repository and run the exact same benchmarks on your hardware:

Terminal 
# 1. Run benchmarks with memory alloc reporting
go test -bench=Benchmark -benchmem -count=3 ./tests/...

# 2. Run the 10,000 concurrent load test with race detector
go test -v -race -run=TestLoad10000ConcurrentRequests ./tests/...
