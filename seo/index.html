SEO & Sitemap Generator

Zero-dependency utilities for generating compliant Google XML Sitemaps, dynamic robots.txt, and Schema.org JSON-LD structured metadata in Go.

Why Server-Side Rendered SEO?

Search engine crawlers (Googlebot, Bingbot, Yandex) and social media scrapers (Twitter Card, Facebook OpenGraph, Discord, WhatsApp) prefer instantaneous, pure HTML content. RHUI produces semantic HTML that ranks higher and renders instant link previews.

XML Sitemap Generator

Use github.com/suserc0de/rhui/pkg/seo to programmatically build search-engine indexable sitemaps.

sitemap_example.go 
package main

import (
    "time"
    "github.com/suserc0de/rhui/pkg/seo"
)

func generateSitemap() []byte {
    sm := seo.NewSitemap()

    // Add high-priority landing page
    sm.Add(seo.SitemapURL{
        Loc:        "https://example.com/",
        LastMod:    time.Now().Format("2006-01-02"),
        ChangeFreq: seo.Daily,
        Priority:   1.0,
    })

    // Add documentation pages
    sm.Add(seo.SitemapURL{
        Loc:        "https://example.com/docs/",
        LastMod:    time.Now().Format("2006-01-02"),
        ChangeFreq: seo.Weekly,
        Priority:   0.8,
    })

    xmlBytes, _ := sm.XML()
    return xmlBytes
}

Schema.org JSON-LD Structured Data

Inject rich snippets into your template headers to achieve search rich-cards (e.g. Products, Articles, FAQs, and BreadcrumbList).

jsonld_example.go 
// Format JSON-LD script for RHUI template insertion
articleMeta := seo.JSONLD(map[string]any{
    "@context":    "https://schema.org",
    "@type":       "TechArticle",
    "headline":    "Mastering Go Web Components with RHUI",
    "author": map[string]any{
        "@type": "Person",
        "name":  "M Ridwan Haqi",
    },
})

Serving Sitemap via HTTP Handler

Serve sitemaps dynamically with automatic caching headers:

http_serve.go 
http.HandleFunc("/sitemap.xml", func(w http.ResponseWriter, r *http.Request) {
    w.Header().Set("Content-Type", "application/xml; charset=utf-8")
    w.Header().Set("Cache-Control", "public, max-age=86400")
    w.Write(generateSitemap())
})
