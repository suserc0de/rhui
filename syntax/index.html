Syntax & Directives

RHUI provides intuitive declarative directives for conditionals, iteration loops, and piped formatters.

1. Conditionals (`<if>` and `<else>`)

Render markup conditionally based on expressions evaluated in a safe sandbox:

Example 
<if test="len(Users) > 0">
  <p>Active Members: {{ len(Users) }}</p>
</if>
<else>
  <p class="text-muted">No users registered yet.</p>
</else>

2. Loops with Iteration Metadata (`<each>`)

Loop over slices or arrays with <each items="..." as="...">. RHUI automatically injects local loop variables:

Variable Type Description
@indexint0-based index
@countint1-based counter
@firstboolTrue if first element
@lastboolTrue if last element
@evenboolTrue for even rows
@oddboolTrue for odd rows
Loop Example 
<table>
  <tbody>
    <each items="Users" as="u">
      <tr :class="@even ? 'bg-gray-100' : 'bg-white'">
        <td>{{ @count }}</td>
        <td>{{ u.Name }}</td>
        <if test="@last">
          <td><span class="badge">Latest</span></td>
        </if>
      </tr>
    </each>
  </tbody>
</table>

3. Pipe Filters (`{{ val | filter }}`)

Transform and format values directly in template interpolations using the pipe operator |:

Pipe Filters Example 
<!-- Text casing and trimming -->
<p>{{ User.Name | trim | upper }}</p>

<!-- Currency formatting -->
<p>Price: {{ Product.Price | rupiah }}</p>

<!-- Date formatting -->
<p>Created: {{ Order.CreatedAt | dateFormat("02 Jan 2006") }}</p>

<!-- Fallback value -->
<p>Bio: {{ User.Bio | default("No bio available.") }}</p>

4. Registering Custom Filters

You can easily register custom Go functions as filters via engine.RegisterFilter:

main.go 
engine.RegisterFilter("truncate", func(val any, maxLen int) string {
    str := fmt.Sprint(val)
    if len(str) > maxLen {
        return str[:maxLen] + "..."
    }
    return str
})

// In template: {{ Article.Body | truncate(100) }}
