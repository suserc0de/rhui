Syntax & Directives

Intuitive HTML-like directives for branching logic, loop iteration with position metadata, and pipelined filter transformations.

Expression Interpolation

Values are interpolated with double curly braces {{ expression }}. All expressions are sandboxed, preventing arbitrary reflection attacks:

syntax_example.rhui 
<p>Hello, {{ user.Name }}!</p>
<p>Item Total: {{ quantity * price }}</p>

Conditionals: <if>, <else-if>, and <else>

Branch rendering based on boolean conditions, comparisons (==, !=, >, <=), and logical operators (&&, ||, !):

conditional_example.rhui 
<if condition="user.IsAdmin">
  <span class="badge-admin">Administrator</span>
<else-if condition="user.Role == 'moderator'">
  <span class="badge-mod">Moderator</span>
<else />
  <span class="badge-user">Standard Member</span>
</if>

Loops & Position Metadata (@first, @last, @even, @odd)

Iterate over slices, arrays, or maps with <each items="..." as="...">. RHUI automatically injects contextual loop variables:

loop_example.rhui 
<ul class="divide-y divide-slate-800">
  <each items="products" as="item">
    <li class="py-3 flex justify-between {{ @even ? 'bg-slate-800/40' : '' }}">
      <span>{{ @index + 1 }}. {{ item.Name }}</span>
      <span class="font-mono text-emerald-400">{{ item.Price | rupiah }}</span>

      <if condition="@last">
        <span class="text-xs text-slate-500">(End of catalog)</span>
      </if>
    </li>
  </each>
</ul>

Pipe Filters (|)

Transform data right inside template interpolations using the pipe operator |. Filters can also be chained:

filters_example.rhui 
<!-- Case and formatting -->
<h1>{{ title | upper }}</h1>
<p>{{ description | truncate(120) }}</p>

<!-- Currency & Localization (Indonesian Rupiah) -->
<span>{{ totalAmount | rupiah }}</span> <!-- Output: Rp 150.000 -->

<!-- Date formatting -->
<time>{{ createdAt | dateFormat('2006-01-02') }}</time>
