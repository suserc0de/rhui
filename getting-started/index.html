Getting Started with RHUI

Step-by-step walkthrough to get RHUI installed, set up your template directories, and serve your first reactive server-side rendered component.

1. Prerequisites

RHUI is designed to be lightweight, fast, and self-contained. It only requires:

  • Go 1.26+ installed on your machine.
  • Standard Go module initialized in your project workspace (go mod init).
  • Zero Node.js, Webpack, or Vite prerequisites. Pure Go execution.

2. Installation

Add RHUI to your Go project using the standard package manager:

Terminal 
go get github.com/suserc0de/rhui

3. Recommended Directory Structure

Separate components, layouts, and page templates to maximize reusability across your application:

Directory Layout 
my-app/
├── main.go
├── views/
│   ├── components/         # Reusable custom components
│   │   ├── Button.rhui
│   │   ├── Card.rhui
│   │   └── Alert.rhui
│   ├── layouts/            # Master HTML layouts
│   │   └── app.rhui
│   └── pages/              # View entry points
│       ├── home.rhui
│       └── dashboard.rhui
└── go.mod

4. Your First RHUI Application

Here is a complete, runnable HTTP server rendering a component with props and slots:

main.go 
package main

import (
    "log"
    "net/http"
    "github.com/suserc0de/rhui"
)

func main() {
    // Initialize engine
    engine := rhui.NewEngine(rhui.EngineOptions{
        ViewsDir: "./views",
        AutoReload: true, // Hot reload in development
    })

    http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
        // Pass any map or typed struct directly (v1.0.8 reflection scope)
        data := map[string]any{
            "Title": "Welcome to RHUI",
            "User":  "Ridwan Haqi",
        }
        if err := engine.Render(w, "pages/home.rhui", data); err != nil {
            http.Error(w, err.Error(), http.StatusInternalServerError)
        }
    })

    log.Println("Server started at http://localhost:8080")
    log.Fatal(http.ListenAndServe(":8080", nil))
}

5. VS Code Syntax Highlighting

Enable syntax highlighting for .rhui files by mapping the extension to HTML in your VS Code settings:

.vscode/settings.json 
{
  "files.associations": {
    "*.rhui": "html"
  }
}
