Getting Started with RHUI

RHUI is designed to be completely zero-config and plug-and-play. Follow this guide to install, configure, and start building component-based UIs in pure Go.

1. Prerequisites

Ensure you have Go installed on your machine. RHUI targets Go 1.26 or higher for optimal memory efficiency and language features.

Terminal 
go version
# Output: go version go1.26.0 linux/amd64

2. Installation

Install the RHUI package into your Go module:

Terminal 
go get github.com/coderhaqi/rhui

3. Recommended Project Structure

Organize your templates clearly by separating components, layouts, and page views:

Directory Layout 
my-app/
├── main.go
├── templates/
│   ├── components/         # Reusable UI components
│   │   ├── Button.rhui
│   │   ├── Card.rhui
│   │   └── Alert.rhui
│   ├── layouts/            # Master page wrappers
│   │   └── main.rhui
│   └── pages/              # Application pages
│       ├── home.rhui
│       └── dashboard.rhui
└── go.mod

4. Your First RHUI Application

Here is a complete, runnable HTTP server rendering a component with props and slots:

main.go 
package main

import (
	"log"
	"net/http"

	"github.com/coderhaqi/rhui"
)

func main() {
	// Initialize RHUI engine
	engine, err := rhui.New(
		rhui.WithDir("templates"),
		rhui.WithExtension(".rhui"),
		rhui.WithDevMode(true), // Enable hot-reload during local development
	)
	if err != nil {
		log.Fatalf("failed to init RHUI: %v", err)
	}

	http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
		data := map[string]any{
			"Title": "Welcome to RHUI",
			"Users": []string{"Alice", "Bob", "Charlie"},
		}

		w.Header().Set("Content-Type", "text/html; charset=utf-8")
		if err := engine.Render(w, "pages/home", data); err != nil {
			http.Error(w, err.Error(), 500)
		}
	})

	log.Println("Server running at http://localhost:8080")
	log.Fatal(http.ListenAndServe(":8080", nil))
}

5. VS Code Syntax Highlighting

To enable syntax coloring for .rhui files, simply add this line to your VS Code settings.json:

.vscode/settings.json 
{
  "files.associations": {
    "*.rhui": "html"
  }
}
